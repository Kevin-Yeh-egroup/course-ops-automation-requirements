學員操作材料

課堂練習包

一份可直接在課堂上照著填的練習包，協助同仁把真實工作講清楚、拆成流程、留下可檢查成果與確認點。

這份練習包不是要大家背固定句子，而是幫學員把一件工作說清楚：為什麼要做、手上有什麼、平常怎麼做、哪裡容易出錯、最後要交付什麼。
你現在在第 3 步：打開練習包。

先填需求說明卡與工作流程整理卡。填完後，到操作題目頁看真實案例，再回來檢查自己的工作是否說清楚。

下一步：選操作題目

練習包內容

1. 工作流程整理卡

把工作拆成開始條件、資料來源、處理步驟、確認責任與輸出。

2. 需求說明卡

用白話說清楚目的、資料、希望 Codex 協助的範圍與不能做的事。

3. 四題真實案例任務單

日週月報營運雷達、逐字稿內容、名詞/派薪檢查、課程改版包。

4. 互動歷程整理卡

記錄自己怎麼和 Codex 來回修正，哪些地方越講越清楚。

5. 確認清單

把外部發送、正式資料更新、金額、個資與正式判斷標出來。

6. 工具化程度

知道一次性整理、固定做法與分步協助的差別。

工作流程整理卡

  1. 這件工作什麼時候開始？
  2. 手上有哪些資料？資料在哪裡？
  3. 平常會怎麼整理、檢查或轉換？
  4. 哪些地方最容易漏，或需要人判斷？
  5. 最後要交付提醒、草稿、表格、文件或 checklist？
  6. 我要怎麼跟同事或主管說明這不是全自動，而是可檢查的草稿或清單？

成果檢查表

  1. 輸出有沒有回答原本的工作問題？
  2. 日期、金額、人名、單位、地點是否需要人確認？
  3. 是否清楚列出可修改使用、需確認、需補資料？
  4. 下次再跑時，資料與需求說明是否足夠清楚？
  5. 這次有沒有省下重複整理或找缺漏的時間？

需求說明卡

要說清楚的事學員可以這樣想
我要達到的目的這件工作最後要讓誰比較省力？要避免什麼漏掉？
目前手上有什麼有表格、錄音、逐字稿、訊息紀錄、舊教材，還是只有口頭需求？
平常怎麼做先做哪一步？中間要看哪些資料？最後要交付什麼？
最容易出錯的地方日期、人名、金額、對外語氣、正式資料更新，哪一種最不能錯？
希望 Codex 先協助哪裡先整理、先分類、先找缺漏、先做草稿，還是先幫我拆步驟？
哪些一定要人確認凡是發送、寫回、公開、定案、派薪、個資與正式承諾，都要先停下來確認。

互動歷程整理卡

第一輪

我先說明情境和目的，不急著要求 Codex 給最後答案。

第二輪

我看 Codex 的整理結果，補充資料來源、缺漏、對象與不能做的事。

第三輪

我請 Codex 把工作切成流程，並列出需要人確認的地方。

工具化程度

這裡只先判斷做到哪一步。

是一次性整理、固定做法，還是未來可能分步協助？完整說明放在下一頁，避免在練習包重複講一遍。

確認清單

可修改使用

摘要、清單、草稿、檢查表、流程草圖。

需要人確認

日期、金額、稱謂、收件人、對外語氣、正式欄位。

需要保留人工決策

外部發送、正式資料更新、個資揭露、金流、核銷或月結相關判斷。
