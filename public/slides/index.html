課程完成品

下課帶走一份練習包

每個人用一段真實行政工作，完成一個小而可重複的 Codex 實驗。

1. 行政題目

選最常重複、最常漏項，或明天就會用到的一小段工作。

2. 工作流程草圖

寫出什麼時候開始、手上有什麼、誰要確認、最後交什麼。

3. 可重複指令

把情境、資料、輸出格式與人工確認點寫成下次能再用的句型。

4. Codex 產出

一份草稿、檢查表、提醒清單、異常表或可交接 checklist。

5. 人工確認清單

標出哪些可修改使用、哪些需要確認、哪些需要補資料。

6. 後續改善清單

知道下一次指令、資料或流程可以怎麼調整。

開啟完整練習包，可直接照著填工作流程整理卡、共用指令模板與成果檢查表。

操作流程

一題照這七步走

1. 說明情境

現在遇到什麼行政工作？

2. 提供資料

貼上安全範例、副本或低風險素材。

3. 指定輸出

表格、清單、草稿、流程或 checklist。

4. 標出確認點

哪些地方要補問、要人看、要保留判斷。

5. 先拆工作

請 Codex 先整理步驟，再產出草稿。

6. 人工檢查

看有沒有誤解、漏項或語氣不合。

7. 要求修正版

把修正意見變成下一版輸出。

安全使用方式

學會把成果變得可確認

會練會

整理、摘要、檢查缺漏，產出可修正的草稿。

會標出

哪些內容要人工確認、由誰確認、何時才能使用。

會帶走

一份可重複指令、一份工作檢查表與後續改善清單。

安全不是把事情停住，而是讓下一步更清楚、更好交接。

每題都照同一個節奏：先準備資料、請 Codex 產出、再用人工確認清單檢查。

課程提醒與每日工作台

倒推提醒、整理待辦、列出等待回覆與人工確認事項。

逐字稿與內容草稿

把紀錄整理成摘要、公告、文章骨架或社群文案草稿。

表格狀態與核銷檢查

只讀檢查缺漏、重複、衝突與異常，整理確認清單。

活動行政包

整理流程、分工、通知草稿、風險清單與可交接 checklist。

開啟四個練習操作說明，可查看每題的準備資料、操作步驟與可複製指令。

題目一

課程提醒與每日工作台

先準備

一筆課程資料、日期時間地點、目前已知狀態與等待回覆事項。

照這樣做

請 Codex 分成今日到期、已逾期、等待回覆、需要人工確認，並寫提醒草稿。

檢查成果

確認日期、對象、提醒文字與是否涉及外部發送或正式資料更新。

練習重點：把行事曆和表格資訊整理成可人工確認、可貼上使用的提醒。

題目二

逐字稿與內容草稿

先準備

一段逐字稿或音檔摘要、活動名稱、讀者與希望輸出的格式。

照這樣做

請 Codex 先抓主題與待確認事實，再產出摘要、文章草稿或社群短文。

檢查成果

確認專有名詞、日期、人名、對外可發布程度與台灣職場語氣。

練習重點：讓內容先成形，再由人確認語氣、事實與可發布程度。

題目三

表格狀態與核銷檢查

先準備

一份表格或 CSV、必要欄位、日期/狀態/金額的檢查規則。

照這樣做

請 Codex 只讀檢查缺漏、重複、格式錯、狀態衝突與低信心資料。

檢查成果

確認來源列、異常原因與需要人工補問的欄位；金額只做試算。

練習重點：先做只讀檢查，把要問人的地方清楚列出來。

題目四

活動行政包

先準備

活動日期地點、對象人數、工作人員、物資、場地資訊與既有範本。

照這樣做

請 Codex 拆成課前、課中、課後，產出分工、通知、物資與風險清單。

檢查成果

確認場地、餐食、名單、外部通知、個資揭露與課後建檔事項。

練習重點：把活動行政拆成可交接的清單，降低漏項。

檢查輸出

看輸出時問三件事

有沒有幫我省整理時間？

資料是否更清楚、待辦是否更集中？

有沒有漏掉重要判斷？

需要人確認的地方是否有列出來？

下次能不能重跑？

指令、資料格式與檢查方式是否足夠清楚？

效果記錄

用簡單表格留下證據

原本花多久？

估計原本整理、查缺漏、寫草稿需要多少時間。

Codex 幫到哪裡？

記錄省下的整理時間與仍需人工確認的部分。

下一步怎麼改？

改指令、補資料、整理成方法小抄，或暫時維持人工。

升級語言

指令、方法小抄、助理角色卡怎麼分

指令

一次請 Codex 幫你做一版。

方法小抄

同一類工作跑過幾次後，把穩定做法寫下來。

助理角色卡

把任務、邊界、資料來源、檢查方式寫清楚。

這堂課先學會分辨與寫草稿，讓之後的工具化更穩。

收尾

今天下課前，請留下三樣東西

  • 一個明天可以繼續試的真實行政工作任務。
  • 一段可重複使用的 Codex 指令。
  • 一份人工確認清單，知道下一步要問誰、補什麼、改哪裡。

穩定跑過幾次後，再評估要不要整理成方法小抄、助理角色卡、表格工具或正式流程。
