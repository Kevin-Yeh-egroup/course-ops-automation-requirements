課程完成品

下課帶走一份練習包

每個人用一段真實行政工作，完成一個小而可重複的 Codex 實驗。

1. 行政題目

選最常重複、最常漏項，或明天就會用到的一小段工作。

2. 工作流程草圖

寫出什麼時候開始、手上有什麼、誰要確認、最後交什麼。

3. 可重複指令

把情境、資料、輸出格式與人工確認點寫成下次能再用的句型。

4. Codex 產出

一份草稿、檢查表、提醒清單、異常表或可交接 checklist。

5. 人工確認清單

標出哪些可修改使用、哪些需要確認、哪些需要補資料。

6. 後續改善清單

知道下一次指令、資料或流程可以怎麼調整。

開啟完整練習包，可直接照著填工作流程整理卡、共用指令模板與成果檢查表。

使用心智模型

像和一位會協助執行工作的專案秘書開會

Codex 不是一次問答就結束。你可以持續補資料、修方向、請它重做，直到成果可以拿來使用。

你負責主持

說明目標、背景、限制、判斷標準與最後要交付的樣子。

Codex 協助執行

整理資料、拆流程、產草稿、列出疑點與人工確認點。

你負責確認

檢查事實、語氣、風險，以及成果是否能正式使用。

開會方式

先說「我要完成什麼」，再逐步補資料、請 Codex 修改、要求它標出需要人判斷的地方。

完成任務

不是第一次輸出就算完成，而是討論到交付成果可讀、可查、可修、可交接。

操作流程

一題照這七步走

1. 說明情境

現在遇到什麼行政工作？

2. 提供資料

貼上安全範例、副本或低風險素材。

3. 指定輸出

表格、清單、草稿、流程或 checklist。

4. 標出確認點

哪些地方要補問、要人看、要保留判斷。

5. 先拆工作

請 Codex 先整理步驟，再產出草稿。

6. 人工檢查

看有沒有誤解、漏項或語氣不合。

7. 要求修正版

把修正意見變成下一版輸出。

安全使用方式

學會把成果變得可確認

會練會

整理、摘要、檢查缺漏，產出可修正的草稿。

會標出

哪些內容要人工確認、由誰確認、何時才能使用。

會帶走

一份可重複指令、一份工作檢查表與後續改善清單。

安全不是把事情停住，而是讓下一步更清楚、更好交接。

四個可選題目

四題都照同一個節奏操作

學員不用四題全做。共同示範後，每個人選最接近自己工作的一題，照下面三步跑一次。

1. 選題與貼資料

選一段低風險、明天就可能用到的工作，貼上範例或副本。

2. 用短版指令產出

說清楚要整理、檢查或產草稿，要求 Codex 列出人工確認點。

3. 人工檢查後修正

檢查日期、金額、人名、外部發送與正式資料更新，再要求修正版。

可選題目

課程提醒、逐字稿內容、表格檢查、活動行政包。

下課留下

一段可重複指令、一份 Codex 產出、一份人工確認清單。

開啟四個練習操作說明，可查看每題的準備資料、操作步驟與可複製指令。

題目一

課程提醒與每日工作台

把課程資料整理成今天可以處理的待辦與提醒草稿。

學員怎麼做
  1. 貼上一筆課程或活動資料。
  2. 補上日期、地點、對象、負責人與目前狀態。
  3. 請 Codex 分成今日到期、已逾期、等待回覆、需確認。
  4. 檢查日期與對象，再把提醒草稿改成自己的語氣。
請把以下課程資料整理成今日課務工作台。 請輸出：今日到期、已逾期、等待回覆、需要人工確認、可修改提醒草稿。 如果資料不足，請列出補問問題，不要自己猜。 資料：
先準備

課程資料、日期時間地點、負責人、等待回覆事項。

會產出

工作台、提醒清單、等待回覆追蹤、提醒草稿。

要檢查

日期、對象、提醒文字、外部發送與正式資料更新。

題目二

逐字稿與內容草稿

把逐字稿先整理成摘要與可修改草稿，再由人確認事實與語氣。

學員怎麼做
  1. 貼上一段逐字稿、會議紀錄或音檔摘要。
  2. 說明讀者是同仁、學員、合作單位或社群。
  3. 請 Codex 先抓重點與待確認事實，再產草稿。
  4. 人工確認人名、日期、專有名詞與可發布程度。
請將以下逐字稿整理成內容草稿。 請輸出：一段摘要、三個重點、文章草稿、社群短文、需要人工確認的事實清單。 請使用台灣職場常用的繁體中文語氣。 資料：
先準備

逐字稿或摘要、活動名稱、讀者、輸出格式。

會產出

摘要、文章草稿、社群短文、待確認清單。

要檢查

事實、語氣、可公開程度、是否忠於原意。

題目三

表格狀態與核銷檢查

先做只讀檢查，把缺漏、衝突、低信心資料列出來，不直接下正式結論。

學員怎麼做
  1. 貼上表格片段或上傳表格副本。
  2. 說明哪些欄位必填、哪些規則要檢查。
  3. 請 Codex 找缺漏、重複、格式錯與狀態衝突。
  4. 保留來源列，逐項確認哪些要補問或修正。
請只讀檢查以下表格資料。 請列出：缺漏欄位、格式異常、重複資料、狀態衝突、需要人工確認的金額或日期。 若資料不足，請列出補問問題，不要做正式核銷或付款結論。 資料：
先準備

表格副本、必要欄位、日期/狀態/金額規則。

會產出

異常清單、補問清單、人工確認清單。

要檢查

來源列、異常原因、金額只做試算。

題目四

活動行政包

把活動拆成課前、課中、課後，產生可交接的流程與清單。

學員怎麼做
  1. 貼上活動日期、地點、對象、人數與人力資訊。
  2. 列出物資、場地、餐食、通知與既有範本。
  3. 請 Codex 拆成課前、課中、課後，產出分工與 checklist。
  4. 人工確認外部通知、個資揭露、場地餐食與課後建檔。
請把以下活動資料整理成活動行政包。 請輸出：課前/課中/課後流程、分工表、通知草稿、物資清單、風險清單、可交接 checklist。 請把需要人工確認的項目另外列出。 資料：
先準備

活動資訊、人力、物資、場地與既有範本。

會產出

流程、分工、通知草稿、物資與風險清單。

要檢查

場地餐食、名單、外部通知、個資與建檔事項。

檢查輸出

看輸出時問三件事

有沒有幫我省整理時間？

資料是否更清楚、待辦是否更集中？

有沒有漏掉重要判斷？

需要人確認的地方是否有列出來？

下次能不能重跑？

指令、資料格式與檢查方式是否足夠清楚？

效果記錄

用簡單表格留下證據

原本花多久？

估計原本整理、查缺漏、寫草稿需要多少時間。

Codex 幫到哪裡？

記錄省下的整理時間與仍需人工確認的部分。

下一步怎麼改？

改指令、補資料、整理成方法小抄，或暫時維持人工。

升級語言

指令、方法小抄、助理角色卡怎麼分

指令

一次請 Codex 幫你做一版。

方法小抄

同一類工作跑過幾次後，把穩定做法寫下來。

助理角色卡

把任務、邊界、資料來源、檢查方式寫清楚。

這堂課先學會分辨與寫草稿，讓之後的工具化更穩。

收尾

今天下課前，請留下三樣東西

  • 一個明天可以繼續試的真實行政工作任務。
  • 一段可重複使用的 Codex 指令。
  • 一份人工確認清單，知道下一步要問誰、補什麼、改哪裡。

穩定跑過幾次後，再評估要不要整理成方法小抄、助理角色卡、表格工具或正式流程。
