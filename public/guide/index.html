第一次使用小抄

Codex 操作說明

用一頁看懂如何開始和 Codex 討論工作、整理資料、產出草稿，並保留人工確認。

這頁是 Codex 第一次操作小抄，不是完整技術手冊。上課主線仍是：簡報、操作說明、練習包、操作題目、成果檢查；迷路時回到上課入口。
你現在在第 2 步：看操作說明。

先知道怎麼和 Codex 說明工作、指定輸出、標出人工確認點；已經熟悉操作的人可以直接前往練習包。

下一步：打開練習包

今天只要記住三件事

把工作說清楚

說明你正在處理哪一段工作、手上有什麼資料、最後希望拿到什麼成果。

指定輸出格式

請 Codex 產出摘要、清單、草稿、表格或待確認事項，不要只說「幫我整理」。

保留人工確認

日期、金額、人名、外部發送、正式資料更新與個資，都要請 Codex 另外標出來。

第一次打開 Codex

  1. 依照課堂或公司指定方式安裝並登入 Codex。
  2. 先建立一個專用資料夾，例如「課程提醒練習」或「逐字稿摘要練習」。
  3. 只把這次練習需要的資料放進資料夾，避免混入無關檔案。
  4. 第一句先要求只讀取、整理與分析，不要改正式資料。

像開一場工作會議

使用 Codex 時，不一定要一次給完美指令。你可以像和同事或秘書開會一樣，先說明目前遇到的狀況、想完成的結果，以及有哪些限制。Codex 可以協助你一起釐清問題、整理成步驟，並在你確認後接著執行。

第一句可以這樣說

我正在練習用 Codex 處理一段行政工作。 請先只讀取、整理與分析，不要修改檔案、不要寄出訊息、不要寫回正式資料。 我的工作目標是： 我提供的資料是： 我希望你產出： 請特別列出需要人工確認的地方： 如果資料不足，請先問我問題，不要自己猜。

一次操作照這七步走

1. 說明情境

這是什麼工作？為什麼現在要處理？

2. 提供資料

貼上內容、上傳檔案，或說明資料放在哪裡。

3. 指定輸出

說清楚要摘要、清單、草稿、表格或檢查表。

4. 標出人審

請 Codex 把需要人判斷的地方另外列出。

5. 先拆工作

若資料複雜，先請 Codex 拆流程與補問問題。

6. 人工檢查

確認日期、金額、稱謂、事實與對外風險。

7. 要求修正版

把你看完後的修正意見交給 Codex，再產出第二版。

四個行政練習怎麼開始

練習題目先準備一份資料第一個檢查重點
課程提醒與每日工作台一筆課程資料或活動資料日期與倒推提醒是否正確
逐字稿與內容草稿一段逐字稿、會議紀錄或音檔摘要是否有忠於原意
表格狀態與核銷檢查一份表格或 CSV是否保留來源列或辨識依據
活動行政包活動日期、地點、對象與人數分工是否清楚

前往四個操作題目

電子報成效分析延伸範例

原本的 Codex 操作說明用電子報成效分析當情境。這個範例保留在這裡，讓學員看到「同一個方法也能用在報表分析」，但課堂不要求每個人都做電子報。

1. 製作與寄送

先在既有系統完成電子報，寄送後再下載報表。

2. 報表放同一資料夾

把開信、點擊、送達、退信等報表集中，檔名加上日期與活動名稱。

3. 請 Codex 分析

要求它找熱門連結、異常指標、內容區塊表現與下次改善清單。

安全收尾

可以先交給 Codex

整理、摘要、檢查缺漏、產生草稿、列待辦。

一定要人工確認

日期、金額、人名、單位、發票、核銷、月結與對外文字。

交由人工確認後再處理

外部寄送、正式寫回、付款、薪資、月結或含個資的對外發布。
