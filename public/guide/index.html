安裝與準備

先下載 Codex App，再準備一個專用資料夾

第一次使用時，建議先用桌面 App，不要從指令或開發工具開始。請依照自己的電腦選擇版本；如果公司有指定帳號或設備，以公司安排為準。

Windows 電腦 大多數公司電腦請選這個。按下後會開啟 Microsoft Store 或安裝頁。
下載 Windows 版
Mac：Apple Silicon 如果你的 Mac 是 M1、M2、M3、M4 或更新晶片，請選這個。
下載 Mac 版
Mac：Intel 如果你的 Mac 是較早期 Intel 處理器，請選這個版本。
下載 Intel Mac 版

開始前先準備好

  • ✓登入用的帳號：可使用自己的 ChatGPT 帳號；若公司有指定帳號，請用公司提供的帳號。
  • ✓一個練習資料夾：先建立「課程練習資料」，第一次只放課堂範例或可公開練習的檔案。
  • ✓基本權限觀念：看到授權、外掛、連線或修改檔案的提醒時，先停下來看用途，不急著按同意。

第一次安裝照這樣做

照畫面完成安裝，再用練習資料夾測試

第一次先確認「能開啟、能登入、能選資料夾、能回覆你」。等熟悉後，再放入正式工作資料。

1

按上方下載按鈕

Windows 選 Windows 版；Mac 不確定晶片時，點左上角 Apple 圖示，再看「關於這台 Mac」。

2

依畫面完成安裝

看到「安裝」、「取得」、「開啟」或「拖曳到 Applications」時，照畫面提示操作即可。

3

打開 Codex 並登入

用自己的 ChatGPT 帳號登入。若公司有指定帳號，請使用公司提供的帳號。

4

選擇練習資料夾

第一次先選「課程練習資料」這類專用資料夾，不要一開始就選整台電腦或公司正式資料夾。

5

先請 Codex 看資料夾

可以用白話說明：請先只檢查這個資料夾，不要修改檔案，並告訴我裡面有哪些東西。

6

看到權限提醒先確認

如果 Codex 詢問是否要連線、安裝、修改或送出資料，先確認用途；不確定時先暫停，課堂一起看。

7

確認成功標準

能打開 Codex、完成登入、選到練習資料夾，並收到一段看得懂的回覆，就代表第一次準備完成。
