練習 1

課程提醒與每日工作台

今日課務工作台、課前提醒清單、等待回覆追蹤表、內部提醒草稿。

先準備
  • 一筆課程資料或活動資料
  • 日期、時間、地點、對象與負責人
  • 目前已知狀態與等待回覆事項
檢查成果
  • 日期與倒推提醒是否正確
  • 提醒對象是否正確
  • 需要人工確認的地方是否有被標出

操作步驟

  1. 先用工作流程整理卡寫清楚這件事從哪裡開始、最後要產出什麼。
  2. 把資料貼給 Codex，請它整理成「今日到期、已逾期、等待回覆、需要人工確認」。
  3. 請 Codex 依課程日期倒推提醒節點，並把提醒文字寫成可修改草稿。
  4. 人工檢查日期、對象、稱謂、是否有外部發送風險。
  5. 記錄這次節省了哪一段整理時間，以及下次資料要補哪個欄位。

可複製指令

請把以下課程資料整理成今日課務工作台。 請分成：今日到期、已逾期、等待回覆、需要人工確認、可複製提醒草稿。 請列出你判斷的依據，不要自動寄出或改任何正式資料。 資料：

練習 2

逐字稿與內容草稿

逐字稿摘要、活動紀錄、文章草稿、社群短文與待確認清單。

先準備
  • 一段逐字稿、會議紀錄或音檔摘要
  • 活動名稱、用途與讀者
  • 希望輸出的格式
檢查成果
  • 是否有忠於原意
  • 是否標出需要查證的事實
  • 語氣是否適合對內或對外讀者

操作步驟

  1. 先說明這份內容要給誰看，以及要變成摘要、文章、公告還是社群短文。
  2. 請 Codex 先抓出主題、重點、可引用資訊與需要確認的事實。
  3. 請 Codex 產出第一版草稿，再要求它改成適合台灣同仁或合作單位閱讀的語氣。
  4. 人工檢查專有名詞、日期、人名、對外可發布程度。
  5. 留下可重複指令，下一次換逐字稿時可直接套用。

可複製指令

請將以下逐字稿整理成內容草稿。 輸出請包含：一段摘要、三個重點、文章草稿、社群短文、需要人工確認的事實清單。 請使用台灣職場常用的繁體中文語氣，避免誇大或替我做正式發布判斷。 資料：

練習 3

表格狀態與核銷檢查

異常清單、人工確認清單、待補資料清單與詢問草稿。

先準備
  • 一份表格或 CSV
  • 欄位意義與必要欄位
  • 金額、日期或狀態的檢查規則
檢查成果
  • 是否保留來源列或辨識依據
  • 是否只做試算與疑點標記
  • 是否清楚列出需要人工確認的項目

操作步驟

  1. 先告訴 Codex 這張表的用途、哪些欄位一定要有、哪些欄位不能自己猜。
  2. 請 Codex 做只讀檢查，列出缺欄、格式錯、重複、狀態衝突與低信心資料。
  3. 若涉及金額或核銷，請它只做試算與疑點標記，不做正式結論。
  4. 人工確認每一筆異常是否真的需要修正。
  5. 把常見錯誤整理成下次可重複的檢查規則。

可複製指令

請只讀檢查以下表格資料。 請列出：缺漏欄位、格式異常、重複資料、狀態衝突、需要人工確認的金額或日期。 若資料不足，請列出補問問題；不要替我做正式核銷或付款結論。 資料：

練習 4

活動行政包

活動流程、分工表、通知草稿、風險清單與可交接 checklist。

先準備
  • 活動日期、地點、對象與人數
  • 工作人員、講師、物資與場地資訊
  • 既有流程、通知或範本
檢查成果
  • 分工是否清楚
  • 課前/課中/課後是否都有涵蓋
  • 外部通知與個資項目是否有人工確認

操作步驟

  1. 先把活動拆成課前、課中、課後三段。
  2. 請 Codex 依三段整理任務、負責人、截止時間與所需資料。
  3. 請 Codex 產生通知草稿、物資清單、風險清單與可交接 checklist。
  4. 人工檢查場地、餐食、報名名單、外部通知與個資揭露。
  5. 課後用同一份清單補上紀錄、附件與待建檔事項。

可複製指令

請把以下活動資料整理成活動行政包。 請輸出：課前/課中/課後流程、分工表、通知草稿、物資清單、風險清單、可交接 checklist。 請把需要人工確認的場地、餐食、名單、外部通知與個資項目另外列出。 資料：
