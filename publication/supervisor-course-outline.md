# 內部審閱版課綱：行政工作 AI 輔助實驗課

## 課程定位

本課是一堂內部行政工作 AI 輔助入門實作課，不對外招生、不收費。課程目的不是導入正式自動化系統，也不是讓工具取代人工判斷；重點是用實際行政案例協助同仁把重複工作講清楚，先用情境說明目的與流程，再練習和 Codex 來回整理成可檢查的草稿、提醒清單或缺漏檢查表，並建立「哪些可以請工具先整理、哪些必須由人確認、成果要怎麼讓同事或主管看懂」的工作邊界。

## 適合對象

適合負責課務、課程改版、紀錄整理、名詞審核、表格檢查、行政追蹤、通知草稿等重複性工作的同仁。學員不需要資訊背景，但需要能登入工具、操作筆電，並能帶一段低風險、可人工檢查的工作素材或使用講師準備的安全範例。

## 預計時間

建議安排 90 分鐘內。這個時間聚焦工具入口說明、講師示範、共同照做，以及課後自行探索方式；個人工作套用、效果記錄與安全收尾不放在課堂內完成，改由學員課後依自己的工作需求慢慢嘗試。

## 課程目標

1. 讓同仁能用白話說明 AI 可以協助哪些行政工作。
2. 讓同仁能把一段工作拆成目的、資料來源、處理步驟、確認責任與交付結果。
3. 讓同仁看懂講師從真實工作出發，如何一步步把需求說清楚、把範圍切小。
4. 讓同仁用真實案例改寫的安全範例，完成一份需求說明、流程整理、草稿、提醒清單或可交接 checklist。
5. 讓同仁用白話理解一次性整理、Skill 與 Agent 的差別；本課不要求現場正式建立。
6. 課後可依個人工作需求自行套用，並檢核最小成果、說明方式與風險確認點。

## 學員完成品

每位學員下課時至少帶走：

1. 一個課後想自行套用的行政工作題目。
2. 一張「我要達到的目的」需求說明卡。
3. 一張「工作流程」整理卡。
4. 一份共同安全範例產出的草稿、提醒清單或檢查表。
5. 一張確認清單，標出哪些可用、哪些需人確認、哪些不適合 AI 處理。
6. 一份 Agent / Skill 白話理解筆記，知道工作可以逐步工具化到什麼程度。

## 90 分鐘內課程安排

| 時間 | 段落 | 可檢核產出 |
| --- | --- | --- |
| 0:00-0:10 | 課程定位與工具入口 | 學員知道本課會完成共同練習，個人套用留到課後 |
| 0:10-0:25 | Codex 操作說明 | 學員看懂如何說明需求、提供資料、看輸出與標確認責任 |
| 0:25-0:45 | 講師示範一題 | 學員看懂如何把口語需求轉成情境、目的與流程 |
| 0:45-1:15 | 全班照做同一題 | 每位學員用安全範例完成一次需求說明與可檢查輸出 |
| 1:15-1:30 | 課後探索與 Agent / Skill 白話說明 | 學員知道如何把自己的工作套入練習包，也知道後續可以工具化到哪一步 |

## 課程案例類型

課程會使用去識別化或安全範例，並以四類實際行政工作做選題。每題都會先用情境敘述帶入，再呈現「目的、原本流程、互動歷程、Codex 協助範圍與確認點」：

- 日週月報營運雷達：練習把 Gmail、Google Ads、好理家在後台與電子報訊號分層，整理成日報、週報、月報草稿，並標出已確認、部分確認與待補資料。
- 逐字稿與內容草稿：練習把紀錄整理成摘要、公告或文章草稿。
- 自定義名詞與派薪前檢查：練習只讀檢查候選名詞、來源證據、狀態衝突與派薪前待確認事項。
- 課程改版包：練習整理改版目標、案例對應、投影片與練習題修改重點、審閱清單與交接 checklist。

## Agent / Skill 說明方式

課堂不要求學員正式建立全域 Skill 或 Agent，而是先用白話理解：

- 一次性需求：這次先把要做的事、手上的資料、希望得到的結果講清楚，請 Codex 協助整理一版。
- Skill 方法小抄：同一類工作做過幾次後，把穩定步驟、輸出格式與確認點寫下來，下次不用重講。
- Agent 助理角色卡：當工作重複且有例外、風險與人工核准時，把任務、邊界、檢查方式與停止規則寫成固定角色。

這樣安排可以讓同仁理解「可以工具化到什麼程度」，但不會讓課程變成正式系統導入或自動化承諾。課堂仍會要求學員在成果旁邊標出確認點：哪些只是草稿、哪些要補資料、哪些需要主管或本人確認後才能使用。

## 預期效益

這堂課的效益不在於立刻建置大型系統，也不要求學員在課堂內完成自己的工作套用；重點是讓同仁先掌握一個可重複、可檢查的 AI 協作方法。課後可檢核的成果包含：同仁更能說清楚自己的行政流程、較容易找出漏項、能產出可檢查草稿，也知道哪些步驟必須回到人工判斷。

## 課後評估方式

課後若要追蹤成效，可請學員自行探索後回填簡短紀錄：

1. 本次選擇的行政工作題目。
2. 原本最耗時或最容易漏的地方。
3. AI 產出的草稿或檢查表。
4. 哪些內容可直接修改使用。
5. 哪些內容需要人確認。
6. 這份成果要怎麼跟同事、主管或窗口溝通。
7. 下一次需求說明或工作流程要怎麼調整；是否需要補資料、切更細，或更早請人確認。

## 後續確認事項

課程正式安排前，建議先確認三件事：

1. 學員可使用的資料等級：以安全範例、副本或低風險素材為主。
2. 課後評估方式：看學員是否完成需求說明卡、流程整理卡、草稿或檢查表，以及確認清單。
3. 後續擴充邊界：若未來要進入系統寫回、外部寄送或排程自動化，需另行審查權限、資料安全與人工核准流程。
