# Evidence Cards

每份作業先建立一張 evidence card，再進入評分。建議檔名：

```text
S001.md
```

建議內容：

```md
# S001 Evidence Card

## 基本資料
- 學員代號：
- 作業主題：
- 對應情境：課程提醒 / 逐字稿內容 / 表格檢查 / 活動行政包 / 其他
- 原始檔案：

## 工作與資料邊界
- 工作目標：
- 資料來源：
- 不可猜測：
- 不可自動處理：

## 實際產出
- 產出檔案或網址：
- 檢查方式：
- 修正紀錄：

## 人工確認
- 需要確認的日期、金額、人名、單位、地點：
- 外部發送或正式資料更新：
- 個資或公開風險：

## 效果記錄
- 原本大約花多久：
- Codex 幫到哪一段：
- 下一次要補什麼：
```
