# 怡君需求整理

狀態：已依據 Kevin 提供的怡君討論內容與錄音逐字稿完成初版整理。

## 角色定位

怡君目前資料呈現三條主要流程：

1. 每月線上分享會：課前報名表、海報、圖文，課後逐字稿、文章、寄送與社群重點再製。
2. 每週固定 Podcast：公開前剪輯、海報、FB 短文與文章草稿，核心痛點是要快速掌握音檔內容。
3. 交通核銷：依起訖地距離、不同單位公里單價與月底核銷規則計算交通費。

## 一句話需求

怡君需要的不是單一提醒，而是一個「內容發布與核銷草稿工作台」：固定節目和分享會的素材到位後，自動產生摘要、文章草稿、社群文案、寄送清單與交接狀態；交通費則從行事曆或地址資料產生可審核的公里數與金額試算。

## 第一版適合先做

- 分享會課前/課後 checklist：報名表、海報、圖文、逐字稿、文章、寄送對象與社群再製狀態。
- Podcast 公開前 checklist：音檔是否到位、摘要、文章草稿、FB 短文、海報素材與標題待補。
- 內容再製草稿：從逐字稿或音檔摘要產生部落格文章、FB 短文、Canva 圖像提示與 Email 草稿。
- 交接追蹤：確認若琪或其他夥伴知道文章來源、可提取重點的素材位置與發布狀態。
- 交通核銷試算：依起點、終點、公里數、單位費率產生月底核銷草稿，不自動送出。
