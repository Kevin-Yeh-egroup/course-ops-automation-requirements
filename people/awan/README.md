# 阿丸需求整理

狀態：已有先前「分析阿丸需求」與四項表單自動生成 MVP 可參考，已整理成公開頁可放的摘要版。

## 目前判斷

阿丸的工作流不是單純課務排程，而是活動行政的完整前後段：候補詢問、候補名單比對、系統工作區報名搬移、活動通知、活動前文件包、活動後 InfoCenter 紀錄。

在這個 repo 中，阿丸適合放在「活動行政包與候補比對」節點：

- 報名前：候補信件分類、候補表單、可通知名單。
- 報名中：正式場次、系統工作區、已上課紀錄與重複報名比對。
- 活動前：工作流程表、簽到表、學員名單、分組座位表、物資/便當統計。
- 活動後：InfoCenter 建檔草稿、附件清單、活動摘要。

## 既有工具雛形

先前已做過「阿丸四項表單自動生成 MVP」，重點是：

- `course_data.example.json`
- `generate_amaru_forms.py`
- 分組座位表
- 簽到表
- 學員名單
- 工作流程表

這個 MVP 已能產出四份 Word 草稿，但正式使用前仍需要補上 DOCX render QA、原版樣式比對、上游欄位來源與真實資料隱私流程。
