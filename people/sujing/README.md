# 素菁需求整理

狀態：已有先前「分析素菁帳務需求」與月結工作台雛形可參考，已整理成公開頁可放的摘要版。

## 目前判斷

素菁的既有材料偏向「帳務/月結」而不是單純課務提醒。它仍然跟課務高度相關，因為課程、講師、行事曆、Google 表單、InfoCenter 匯出與發票資料，最後會進到人員勞務結算、Ivy 報帳輸出與匯款前檢查。

因此在這個 repo 中，素菁不應該放在「南區課務提醒」同一層，而應該放在課務資料的後端結算節點：

- 前端課務：佩欣、瑜君等角色處理邀約、派課、課前資料、提醒與資料補齊。
- 中段狀態：Google Sheet、Calendar、InfoCenter、Line 或 Email 保留案件狀態。
- 後端結算：素菁需要把課務與其他工作紀錄轉成可對帳、可確認、可輸出的月結資料。

## 既有工具雛形

先前已做過「素菁月結工作台」方向的雛形，重點頁面包含：

- 月結 Dashboard

- 待派薪草稿與差旅交通核銷
