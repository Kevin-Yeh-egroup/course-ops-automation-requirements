# 共用模組：提醒引擎

## 目的

把佩欣、思宜、怡君、瑜君目前已整理出的提醒需求整理成同一套可擴充規則：先產生每日/每週提醒摘要，再逐步接 Calendar、Sheet 狀態欄或工作台。

## 共用提醒型態

| 類型 | 適用對象 | 觸發資料 | 第一版輸出 |
| --- | --- | --- | --- |
| 新案件提醒 | 佩欣、思宜、怡君、瑜君 | 表單新增、InfoCenter 新狀態、Sheet 新列、固定檔期 | 新增清單 |
| 缺漏提醒 | 佩欣、思宜、怡君、瑜君皆適用 | 必填欄位空白、內容過短、格式不符、素材來源缺漏 | 缺漏清單與補問/草稿 |
| 到期提醒 | 佩欣、怡君、瑜君 | 課程日期、核銷截止、課綱/PPT期限、Podcast 公開前一週 | 今日到期與逾期清單 |
| 狀態不同步提醒 | 佩欣、思宜 | InfoCenter、Google Sheet、Calendar 狀態不一致 | 對帳異常清單 |
| 人工核准提醒 | 佩欣、思宜、怡君、瑜君皆適用 | 草稿已產生但尚未確認 | 待確認清單 |

## 怡君內容發布規則

| 規則 | 條件 | 輸出 |
| --- | --- | --- |
| 分享會課前 | 分享會日期已定 | 報名表、海報、圖文 checklist |
| 分享會課後 | 分享會已完成 | 逐字稿、文章、寄送對象與社群重點待辦 |
| Podcast 公開前一週 | 固定檔期接近，音檔或逐字稿已到位 | 摘要、文章、FB 短文與海報提示草稿 |
| Podcast 標題待補 | 內容可處理但標題/檔名未定 | 以檔期追蹤，保留標題待補欄 |
| 交通核銷 | 行事曆或工作紀錄有地點 | 起訖地、公里數、費率與核銷待確認清單 |

## 瑜君南區課務規則

| 規則 | 條件 | 輸出 |
| --- | --- | --- |
| 南區案件 | `指派規劃師` 為瑜君，或課程地點屬南區 | 本週南區案件清單 |
| 待確認日期 | 有期待日期，但正式授課日期未填 | 待確認日期提醒 |
| 待派講師 | 需求已可判斷，但講師安排未填 | 派課摘要草稿 |
| 課前 3-4 週 | 授課日期已確認 | 成員樣貌與特殊需求確認 |
| 課前 2 週 | 授課日期已確認 | 課綱、PPT、媒材追蹤 |
| 課前 1 週 | 授課日期已確認 | 流程、發票、地點、設備確認 |

## No-op 規則

若案件缺少正式日期、講師尚未派定、資料來源不可靠，提醒引擎只產出「待補資料」或「待確認」清單，不建立 Calendar、不寫回 Sheet、不外送訊息。
