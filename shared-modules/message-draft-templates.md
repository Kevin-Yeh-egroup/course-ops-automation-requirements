# 共用模組：訊息草稿模板

## 目的

降低重複整理與複製貼上的時間，但保留人工確認。所有模板第一版都只產生草稿，不自動發送。

## 課務派課摘要

```text
【課程派課摘要】
單位：
窗口：
課程主題：
課程目的：
主要參與對象：
學員樣貌：
期待日期/正式日期：
地點：
時數與人數：
費用/交通/發票：
規劃師補充：
待確認事項：
```

## 課前確認摘要

```text
【課前確認】
課程：
日期時間：
地點：
講師/助教：
當日流程：
設備與媒材：
學員特殊狀況：
發票與核銷：
目前缺漏：
```

## 補問清單

```text
目前資料還需要補齊以下幾點，確認後會比較好安排講師與課程內容：
1. 學員樣貌：
2. 課程期待與主要困擾：
3. 日期/時間/地點：
4. 場地設備：
5. 發票或交通行政：
```

## 每日工作台摘要

