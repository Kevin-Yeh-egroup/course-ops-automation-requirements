# 共用模組：內容再製與發布草稿工作流

## 目的

這個模組整理分享會、Podcast、逐字稿、文章、社群文案與 Email 寄送之間的共用流程。第一版目標不是自動發布，而是把素材到位狀態、內容草稿、交接對象與待確認事項集中到同一個可審核清單。

目前主要參考怡君的線上分享會與每週 Podcast 需求。後續如果其他同仁也需要把課程、活動、訪談或會議內容轉成文章與社群貼文，可合併進來。

## 核心輸入

| 類型 | 例子 | 注意事項 |
| --- | --- | --- |
| 活動資訊 | 分享會主題、日期、講師、報名表、回饋問卷 | 不放完整學員資料到公開頁 |
| 內容素材 | 音檔、逐字稿、剪輯後檔案、既有文章 | 音檔與逐字稿需保留來源位置 |
| 發布渠道 | 好理家摘、循錢師粉專、Podcast 平台、Email | 第一版只產生草稿與待辦 |
| 負責人 | 怡君、仙伯、若琪或其他交接夥伴 | 需要知道誰要拿哪一份素材 |
| 時程 | 每月分享會、每週 Podcast、公開前一週 | 檔名或標題未定時可先以檔期追蹤 |

## 第一版產出

| 產出 | 用途 |
| --- | --- |
| 素材 checklist | 檢查報名表、海報、圖文、音檔、逐字稿、文章位置是否到位 |
| 內容摘要 | 讓怡君快速掌握分享會或 Podcast 內容 |
| 文章草稿 | 產生部落格或好理家摘可修改草稿 |
| 社群短文 | 產生 FB 短文、重點條列與 Canva 圖像提示 |
| Email 草稿 | 產生寄送給回饋問卷填寫者或指定對象的草稿 |
| 交接清單 | 標記若琪或其他夥伴是否知道文章位置與可提取素材 |

## 分享會流程規則

| 節點 | 檢查 | 輸出 |
| --- | --- | --- |
| 課前 | 報名表、海報、圖文是否到位 | 課前 checklist 與缺漏提醒 |
| 課後 1 | 是否已有語音轉文字 | 逐字稿待補或摘要草稿 |
| 課後 2 | 是否已有文章位置 | 好理家摘文章草稿或連結欄位 |
| 課後 3 | 是否有可寄送對象 | Email 草稿與寄送名單待確認 |
| 課後 4 | 若琪是否取得素材 | 社群重點提取交接清單 |

## Podcast 流程規則

| 節點 | 檢查 | 輸出 |
| --- | --- | --- |
| 公開前一週 | 音檔是否到位 | 內容摘要與待補欄位 |
| 草稿產生 | 標題或檔名是否已定 | 可先產文章與短文，標題保留待補 |
| 海報素材 | 是否有主題、關鍵句或圖像方向 | Canva 圖像提示與短文 |
| 公開前確認 | 文章、FB 短文、海報是否都完成 | 發布 checklist，不自動發布 |

## no-op 規則

遇到以下狀況時，只產生待確認清單：

- 音檔、逐字稿或文章來源不存在。
- 活動日期、公開日期或標題未確認。
- 寄送對象來自回饋問卷，但名單尚未確認。
- 內容包含敏感個資、個案、未授權引用或不適合公開資訊。
- 發布渠道與負責人不明。

## 治理邊界

- 不自動寄送 Email。
- 不自動發布部落格、粉專或 Podcast 平台內容。
- 不把完整逐字稿、音檔、學員資料或問卷原文放到公開頁。
- 所有對外內容都先輸出為草稿、來源註記與人工確認清單。
