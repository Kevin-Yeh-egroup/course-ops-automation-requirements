# 共用模組：Google Sheet 欄位字典

## 目的

讓不同工作流都能用同一套欄位治理原則：先辨識來源欄位，再定義必填、狀態、日期、敏感與可寫回欄位。

## 欄位分類

| 類型 | 說明 | 範例 |
| --- | --- | --- |
| 身分欄位 | 用來識別人、單位、案件 | 單位名稱、姓名、電話、Email |
| 需求欄位 | 用來判斷服務內容 | 課程目的、學員樣貌、個案背景、特殊需求 |
| 日期欄位 | 用來產生提醒與倒數 | 授課日期、截止日、派案日、電訪日 |
| 狀態欄位 | 用來判斷下一步 | 已派課、已提醒、已完成、待補件 |
| 行政欄位 | 用來處理費用、發票、交通、核銷 | 鐘點費、發票抬頭、交通補助、住宿 |
| 敏感欄位 | 需要最小揭露與權限控管 | 身分證、個案狀態、身心議題、薪資依據 |

## 第一版欄位治理

1. 不修改原始表單回覆欄位。
2. 若需要追蹤狀態，優先新增少量狀態欄或 companion dashboard。
3. 所有寫回都要保留來源列號、更新時間與人工確認者。
4. AI 摘要不應取代原始資料，只作為可審核草稿。
